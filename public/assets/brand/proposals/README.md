# ARTORA · propostas de logo universal

As duas propostas são estudos para escolha. A marca oficial usada pelo site permanece intacta até a decisão.

## Direções

- **A — Moldura A:** refina o monograma atual e mantém o A geométrico dentro da moldura aberta.
- **B — Horizonte em tela:** cria um símbolo independente de letras com moldura, sol nascente e horizonte pintado.

Cada direção tem símbolo isolado e logotipo horizontal em versões para fundo claro e escuro. Os SVGs têm fundo transparente; os PNGs incluem o respectivo fundo e margem para avatar. A palavra ARTORA é convertida em curvas vetoriais DM Sans para manter o mesmo desenho sem depender de fontes instaladas.

## Comparação

Abra `index.html` no navegador para comparar as duas direções, os fundos e a leitura do símbolo em tamanhos menores.

## Regenerar

Com as dependências já instaladas no projeto, execute `node scripts/generate-logo-proposals.mjs`. O script gera SVGs, PNGs e a prancha comparativa nesta pasta.
