# ARTORA · kit para redes sociais

As artes foram criadas com a paleta existente da Artora: marinho `#14243A` e dourado `#C5A45D`, em linguagem de galeria contemporânea com paisagens pintadas a óleo e molduras luminosas.

| Arquivo | Uso sugerido |
| --- | --- |
| `artora-avatar-art.png` | Imagem de perfil compartilhada para Pinterest, Google e TikTok. O enquadramento central tolera o recorte circular. |
| `artora-cover-pinterest-google.png` | Capa horizontal para Pinterest e imagem de capa do Perfil da Empresa no Google. Ajuste o recorte dentro de cada plataforma. |
| `artora-tiktok-vertical.png` | Fundo vertical para capa de vídeo, post ou conteúdo de marca no TikTok. |

As imagens são fundos visuais sem texto. Para manter o nome e o monograma oficiais nítidos, use os vetores `../artora-logo.svg` ou `../artora-symbol.svg` nas peças que permitirem composição; evite reconstruir a marca com texto gerado.
