# Pré-visualizações da coleção

As versões leves usadas na landing ficam em `optimized/hero-01.jpg` até `hero-20.jpg`. Elas foram geradas a partir dos PNGs originais, reduzidas para no máximo 800 px no lado maior e mantêm a proporção. Cada JPEG contém a marca d’água diagonal “ARTORA • PRÉVIA”.

Os arquivos originais foram guardados em `assets/source/hero/`, fora da pasta pública do site. O gerador unificado `scripts/optimize_showcase_previews.py` recria as prévias do hero e da galeria sem modificar os originais.
